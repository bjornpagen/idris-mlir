**Contract:** every ending has its own exit status from one generated
table (D37): 0 returned, `n` for `exit n` (outside 0 to 255 a crash at
the exit's site, D64), 1 crashed, 111 out of memory, 126 cannot run,
`SIGABRT` internal error, `SIGPIPE` after a flush (D81); messages
`<program>: fatal: <cause>`, the cause's name as data (D80); a program
commits no memory before use, reserves no address space beyond what the
host allows, starts on strict hosts (D35, D36, D65); the small stack is
charged at start (D66), its size computed from code generation's
per-function stack sizes on the final module (C98); no stack probes
(D77); no stack bit (D78); static data by its marker (D89). The driver:
the compiler's own stack small (D33), one out-of-memory handler (C15),
byte-identical output (C16), Rust as its own runtime only (D92).

**End state:** `Spec.Runtime` declares the ending table, printed for the
runtime and the harness; the runtime has one entry per kind of word, no
uniqueness test on a typed exclusive value, no live-cell counter, no
4 GiB reservation, sizes the program's or the host's; the driver
computes the stack bound at link and fails the build on a non-`musttail`
edge inside a cycle of the final module.

**Recipe:** as your report §5 drafts it, amended by D64 to D66, D77,
D78, D80, D81, D89, D91, D108 (its handler side).

**Delete:** `heapRegion` and the 4 GiB reservation, the stack bit in
every header and each test of it, the live-cell counter in shipped
programs, the `Status` root and the hard `idris-mlir:` prefix, every
`assert` (D91).

**QTT:** a typed exclusive value's free reads no count; a static value's
marker is read only past the specialization budget (D89).

**NOT TO DO:** lowering's runtime calls (L21); the D41 template (L13,
which the runtime includes); tests (L19).

**Acceptance:** INT's runs give every ending its status and message on
the four targets, strict hosts start every program, and the stack bound
holds.

**Stop and return:** when the runtime, the table and the driver are
written and your handoff is sent.
