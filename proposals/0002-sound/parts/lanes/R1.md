- `harness/prop/prop.h`, header-only (every function `inline` or a template), exactly these declarations:

```cpp
#pragma once
#include <fuzzer/FuzzedDataProvider.h>
#include <stddef.h>
#include <stdint.h>

#include "idris_rt.h"   // idris_rt_flush, for captureStdout

namespace prop {

// The bytes one case draws from: room for the largest case a property of
// this wave draws (two operands of 8 limbs are 128 bytes; a string of 320
// bytes; a sequence of 300 operations of a few bytes each), with a margin.
inline constexpr size_t caseBytes = 1024;
// The distinct labels one property counts; more are counted as "other".
inline constexpr unsigned classLimit = 64;
// The properties and boxes one program reports.
inline constexpr unsigned propertyLimit = 64;

// splitmix64 (Vigna 2015): state += 0x9E3779B97F4A7C15, then the state mixed
// by (z ^ z >> 30) * 0xBF58476D1CE4E5B9, (z ^ z >> 27) * 0x94D049BB133111EB,
// z ^ z >> 31. From state 0 its outputs are 0xE220A8397B1DCDAF,
// 0x6E789E6AA1B965F4, 0x06C45D188009454F.
uint64_t splitmix64(uint64_t &state);
// Output `index` (from 0) of splitmix64 started at `seed`:
// mix(seed + (index + 1) * 0x9E3779B97F4A7C15). harness/Gen.idr's caseSeed.
uint64_t caseSeed(uint64_t seed, uint64_t index);
// `length` bytes of splitmix64 started at caseSeed(seed, index), each
// output's eight bytes least significant first (by shifts, not memcpy).
void fillCase(uint64_t seed, uint64_t index, uint8_t *bytes, size_t length);

// A case's class, for the report: the last label given.
class Tally {
public:
  void classify(const char *label);   // a string literal
  const char *label() const;          // nullptr when unclassified
private:
  const char *label_ = nullptr;
};

// Swarm testing: `families` (1 to 64) bits, bit i set when the provider's
// next ConsumeBool() is true; never 0: when every bit came out clear, bit 0,
// the simplest family, is set. An exhausted provider gives exactly bit 0.
uint64_t swarm(FuzzedDataProvider &provider, unsigned families);
// One family the mask keeps, uniform over its set bits (one
// ConsumeIntegralInRange over their count); the lowest set bit when the
// provider is exhausted. mask is not 0.
unsigned pick(FuzzedDataProvider &provider, uint64_t mask);

// A line (printf format) saying why the current case or input fails; the
// lines of the case or input a property reports are printed under it.
void explain(const char *format, ...) __attribute__((format(printf, 1, 2)));

// Runs write() with standard output (fd 1) sent to a fresh tmpfile(): stdio
// and the runtime's output buffer (idris_rt_flush) are flushed before the
// switch and after write(), fd 1 is restored, and the bytes written are
// copied into out, at most `capacity`. Returns the count written, which may
// exceed capacity.
template <typename Write> size_t captureStdout(Write write, char *out, size_t capacity);

class Run {
public:
  // PROGRAM [--seed S] [--cases N] [--case I [--bytes L]] [--report FILE];
  // defaults: seed 1, 1000 cases, every case, caseBytes, no report. Any other
  // argument: a usage line on stderr and exit status 2.
  Run(int argc, char **argv);
  // body(FuzzedDataProvider &, Tally &) -> bool, true when the property
  // holds, on cases 0 to N - 1 (or case I alone), each over fillCase(S, i)
  // and its first caseBytes (or L) bytes. At the first case that fails, the
  // byte count is halved while the case still fails, then that case runs
  // once more for its explain() lines. Prints "<name>: ok", or
  // "<name>: failed", "  | case I of seed S, L bytes: rerun with --seed S
  // --case I --bytes L" and "  | <line>" for each explanation. Stdout is
  // flushed after every line.
  template <typename Body> void property(const char *name, Body body);
  // body(uint64_t input) -> bool on every input in [0, count), whatever
  // --case says. Prints "<name>: ok", or "<name>: failed", "  | input I" and
  // the explanation lines of the first input that fails.
  template <typename Body> void box(const char *name, uint64_t count, Body body);
  // Writes the report when --report was given; returns 0 when every
  // property and box held, else 1.
  int finish();
};

} // namespace prop
```

- The report, written by `finish()` to the `--report` file only, never to stdout: a first line `seed <S>, <N> cases a property`; per property `<name>: n=<cases run> classes=<k> f1=<labels seen exactly once> f1/n=<ratio, 4 decimals>` then `  <label>: <count>` per label in byte order (unclassified cases under `unclassified`, overflow under `other`); per box `<name>: box of <count> inputs`. f1/n is the Good–Turing estimate of the chance the next case falls in a class not yet seen: a property whose f1/n stays high needs another family.

```cpp
#pragma once
#include <gmp.h>
#include "idris_rt.h"
#include "prop.h"

// Every function below is inline: the header is included by both programs.
namespace bigmodel {
// The largest operand a property draws: past one limb and two, where to_int,
// to_double and the shifts cross limb boundaries, and cheap per case.
inline constexpr size_t maxLimbs = 8;
// Storage for a persistent big laid out as idris_rt.h:157-167 lays out a
// large big and as idr-lower writes one into static data: count 0,
// info idris_rt_info(0, 0, IDRIS_RT_KIND_BIGNUM), the signed limb count,
// the limbs least significant first. Aligned to a word.
struct Constant { alignas(8) uint64_t words[2 + maxLimbs]; };
// The big of v (at most maxLimbs limbs): the tagged word 2v + 1 when v
// fits 63 bits, else the persistent bignum written into c.
idris_rt_big constant(mpz_srcptr v, Constant &c);
// The value of any big, small or large, counted or persistent, read through
// the documented layout alone (mpz_roinit_n on the limbs, never a runtime call).
void value(idris_rt_big b, mpz_ptr out);
// One representation: odd exactly when the value fits 63 bits; a large one
// an even word whose cell's kind is IDRIS_RT_KIND_BIGNUM, size not 0, top
// limb not 0, value outside [-2^62, 2^62 - 1]. Says what is wrong (prop::explain).
bool canonical(idris_rt_big b);
// The families a big is drawn from, simplest first, and a draw from one.
inline constexpr unsigned families = 8;
void draw(FuzzedDataProvider &p, unsigned family, mpz_ptr out);
}
```

  Families, in this order: 0 small: 0, ±1, ±2; 1 small, drawn in [−2^20, 2^20]; 2 the small range's edges: within 16 of −2^62 or 2^62 − 1, and ±2^61; 3 just past it: within 16 outside it, the int64 and uint64 edges (−2^63, 2^63 − 1, 2^63, 2^64 − 1, ±2^64); 4 one limb, any magnitude below 2^64, any sign; 5 2 to `maxLimbs` limbs drawn with `ConsumeData`; 6 ±2^k and ±2^k ± 1 for k in [0, 64·maxLimbs); 7 2^k − 1 and its negation. Shift amounts have their own families: [0, 63); 60 to 66; up to ±200; negative; and a large big (≥ 2^62) only toward zero (`shr` by it, `shl` by its negation), the one direction `idris_rt.h:507-510` defines for every amount.

- `runtime-bigs/bigs.cpp` properties, in this order, with these exact names:
  1. `add, sub, mul: the integer GMP computes` (mpz_add, mpz_sub, mpz_mul).
  2. `div, mod: Euclidean: a = q*b + r and 0 <= r < |b|` (the defining property, checked with mpz; b drawn nonzero).
  3. `and, or, xor: two's complement, bit by bit` (for every bit index up to the operands' and result's `mpz_sizeinbase(·, 2) + 2`, `mpz_tstbit` of the result is the operation on the operands' bits, and the result's sign is the operation on their signs, so the bits above agree too; GMP's `mpz_tstbit` reads negatives in two's complement).
  4. `shl, shr: a * 2^k and floor(a / 2^k), the other way for k < 0` (`shl`: equal to a times `mpz_ui_pow_ui(2, k)`; `shr`: r·2^k <= a < (r + 1)·2^k).
  5. `neg, cmp, nat_from_big, pred` (−a; the sign of `mpz_cmp`; 0 for a negative, else a; a − 1 for a natural above 0).
  6. `from_int_s, from_int_u, to_int: exact, and to_int modulo 2^64` (`idris_rt_big_to_int` is the low 64 bits in two's complement: `mpz_fdiv_r_2exp(·, 64)`).
  7. `to_double: nearest, ties to even, infinity past the largest` (with `mpq_set_d`, exact: |a − d| is at most the distance to `nextafter(d, ±inf)`; on a tie d's significand is even; d is ±inf exactly when |a| >= 2^1024 − 2^970).
  8. `from_double: truncated toward zero` (for finite x: |r| <= |x| < |r| + 1 and r is 0 or has x's sign; doubles from all exponents).
  9. `laws: commutative, associative, distributive, identities, inverses` (add, mul, and, or, xor commute and associate; mul over add and and over or distribute; a + 0, a·1, a and −1, a or 0, a xor 0 are a; a + neg a, a − a, a xor a are 0; neg (neg a) is a; a xor −1 is −a − 1).
  10. `laws: shifts compose and undo` (shr (shl a k) k = a; shl (shl a j) k = shl a (j + k); shl a k = a · shl 1 k; shr a k = div a (shl 1 k), for j, k >= 0).
  11. `small path = large path on small operands` (for small operands, each entry equals its large path from `Big/Big.h`: `idris_rt_big_add` and `rt::big::addLarge`, sub, mul, neg, and, or, xor, shl, shr, `idris_rt_big_cmp` and `cmpLarge`, `idris_rt_nat_from_big` and `natFromBigLarge`, `idris_rt_big_from_int_u` and `fromUnsignedLarge`, `idris_rt_big_from_int_s` and `largeOfInt64`; compared by value, both canonical).
  12. `box: every pair of edge values, every operation` (exhaustive: the edge set E = {−2^62 − 1, −2^62, −2^62 + 1, −2^61, −2, −1, 0, 1, 2, 2^61, 2^62 − 2, 2^62 − 1, 2^62, 2^63, −2^63, 2^64}, every ordered pair, properties 1 to 6 and 11 on each).
  13. `box: every edge value shifted by every amount in [-130, 130]` (exhaustive, property 4 and canonical form).
  14. `every operation borrows its operands and returns one owned result` (counted operands keep their counts; after the result is released, `idris_rt_live_cells()` is back where it was before the operation; a result that is an operand returned has one more reference, `idris_rt.h:284-288`).
