**Permitted outcome:** mandatory, all seven findings.
- Memory is split from values (S3). Each cell source is its own op, its effects
  those of the memref op it mirrors, declared in ODS. `idr.cell.init` writes a
  cell's fields, its result types inferred.
- `idr.take` takes a cell, and `idr.unpack` takes a value with no cell (mlir-5).
  Which one applies is decided once, by `idr::buildsCell` (S36).
- `idr.reuse` and `idr.con`'s `stack`, `holes` and `dests` are gone.
- A hole at a field that is no box is refused in every build. An atom has no
  cell type and no take.

Nothing is optional.

**Fixed decisions:**
- **S36, in `Ownership.h`:**
  ```cpp
  // Whether constructor `tag` of a value of `type` (at any grade) has a cell
  // of its own: the value is a box and the constructor is not an atom. The
  // one place the two cases meet: a cell's con becomes cell.new and
  // cell.init after idr-rc, and its take is idr.take; any other con stays
  // idr.con, and its take is idr.unpack.
  bool buildsCell(mlir::Type type, Tag tag);
  ```
  It is defined in `OpsOwnership.cpp` as `isBoxed(type) &&
  !dataTypeOf(type).isAtom(tag)`.
- **The cell type, the four cell ops and the two takes** replace the old reuse
  op and `Idr_TakeOp`. All were checked with the pinned `mlir-tblgen` (`ops`
  and `typedefs`):
  ```tablegen
  def Idr_CellType : Idr_Type<"Cell", "cell"> {
    let summary = "the memory of one cell of a constructor, its header written, its fields not yet";
    let parameters = (ins "::idr::BoxType":$box, Idr_TagParameter:$tag);
    let hasCustomAssemblyFormat = 1;
    let genVerifyDecl = 1;
  }
  def Idr_CellNewOp : Idr_OwnedOp<"cell.new"> {
    let results = (outs Res<Idr_CellType, "", [MemAlloc<DefaultResource, 0, FullEffect>]>:$cell);
    let assemblyFormat = "attr-dict `:` qualified(type($cell))";
  }
  def Idr_CellStackOp : Idr_OwnedOp<"cell.stack"> {
    let results = (outs Res<Idr_CellType, "",
        [MemAlloc<AutomaticAllocationScopeResource, 0, FullEffect>]>:$cell);
    let assemblyFormat = "attr-dict `:` qualified(type($cell))";
  }
  def Idr_CellRecycleOp : Idr_OwnedOp<"cell.recycle", [DeclareOpInterfaceMethods<Idr_FlowOpInterface>]> {
    let arguments = (ins Arg<Idr_OwnedToken, "", [MemFreeAt<0, FullEffect>]>:$token);
    let results = (outs Res<Idr_CellType, "", [MemAlloc<DefaultResource, 1, FullEffect>]>:$cell);
    let assemblyFormat = "$token `:` type($token) attr-dict `->` qualified(type($cell))";
  }
  def Idr_CellInitOp : Idr_OwnedOp<"cell.init", [DeclareOpInterfaceMethods<Idr_FlowOpInterface>,
      DeclareOpInterfaceMethods<InferTypeOpInterface, ["isCompatibleReturnTypes"]>,
      PredOpTrait<"its fields are its cell's constructor's, the holes aside, each at the field's type or owned",
                  CPred<"::idr::detail::fillsCell(::llvm::cast<::idr::CellInitOp>(&$_op))">>]> {
    let arguments = (ins Arg<Idr_CellType, "", [MemWrite]>:$cell, Variadic<AnyType>:$fields,
                         DefaultValuedAttr<Idr_HolePositions, "{}">:$holes);
    let results = (outs Idr_BoxValue:$result, Variadic<Idr_DestType>:$dests);
    let assemblyFormat = [{
      $cell `:` qualified(type($cell)) custom<Fields>($fields, type($fields), $holes) attr-dict
      custom<CellResult>(type($result), ref(type($cell)))
      custom<CellDests>(type($dests), ref(type($cell)), ref($holes))
    }];
    let skipDefaultBuilders = 1;
    let builders = [OpBuilder<(ins "::mlir::Value":$cell, "::mlir::ValueRange":$fields,
                                   CArg<"::llvm::ArrayRef<int32_t>", "{}">:$holes)>];
    let extraClassDeclaration = [{
      ::idr::DataType getDataType();
      ::idr::Tag getTag();
      ::mlir::Value getField(unsigned index);
      ::mlir::Value getDest(unsigned index);
      // The destination of each hole of `cell`'s constructor; a hole out of
      // range or at a field that is no box gives none (inference refuses it).
      static ::llvm::SmallVector<::mlir::Type> destTypes(CellType cell, ::llvm::ArrayRef<int32_t> holes);
    }];
  }
  def Idr_TakeOp : Idr_OwnedOp<"take", [
      DeclareOpInterfaceMethods<InferTypeOpInterface, ["isCompatibleReturnTypes"]>,
      DeclareOpInterfaceMethods<Idr_FlowOpInterface>]> {
    let arguments = (ins Arg<Idr_OwnType, "", [MemRead, MemWrite, MemFree]>:$value, Idr_TagAttr:$tag);
    let results = (outs Idr_OwnedToken:$token, Variadic<AnyType>:$fields);
    let assemblyFormat = [{
      $value `:` type($value) custom<CtorRef>(ref(type($value)), $tag) attr-dict
      `->` `(` type($token) (`,` type($fields)^)? `)`
    }];
    let skipDefaultBuilders = 1;
    let builders = [OpBuilder<(ins "::mlir::Value":$value, "::idr::Tag":$tag)>];
    let extraClassDeclaration = [{ ::idr::DataType getDataType(); }];
  }
  def Idr_UnpackOp : Idr_OwnedOp<"unpack", [Idr_ConsumesOnly,
      DeclareOpInterfaceMethods<InferTypeOpInterface, ["isCompatibleReturnTypes"]>,
      DeclareOpInterfaceMethods<Idr_FlowOpInterface>]> {
    let arguments = (ins Idr_OwnType:$value, Idr_TagAttr:$tag);
    let results = (outs Variadic<AnyType>:$fields);
    let assemblyFormat = [{
      $value `:` type($value) custom<CtorRef>(ref(type($value)), $tag) attr-dict
      `->` `(` type($fields) `)`
    }];
    let skipDefaultBuilders = 1;
    let builders = [OpBuilder<(ins "::mlir::Value":$value, "::idr::Tag":$tag)>];
    let extraClassDeclaration = [{ ::idr::DataType getDataType(); }];
  }
  ```

- **`CellType`'s C++ in `OpsOwnership.cpp`:**
  - `parse`/`print` of `!idr.cell<!idr.box<!L>, @Cons>`: the box type, then the
    constructor by name through `parseCtorRef`/`printCtorRef`.
  - `verify`: the tag is in range, and `buildsCell(box, tag)` holds, so an atom

  - The cell has no grade.
  - The Idris generator skips a custom type format.
- **Inference**, each function total on bad input (`failure()` with an error at
  the location):
  - `TakeOp` requires `buildsCell(value, tag)`. It gives
    `owned(TokenType::get(ctx))`, then each field `t = fieldType(valueType, f)`
    as `holdsReferences(t) ? owned(t) : t`.
  - `UnpackOp` requires `!buildsCell(value, tag)` and gives the fields alike.
    An atom gives none.
  - `CellInitOp` gives `owned(cell.getBox())`, then `destTypes(cell, holes)`.
    It refuses a hole out of range, or a hole at a field that is no box, with
    "has a hole at field N of type T, which is no box: only a box's field is
    written through a destination" (ir-ops-8).
  - Each `isCompatibleReturnTypes`: equal sizes, and pairwise `a == b ||
    (isOwned(a) && isOwned(b) && view(a) == view(b))` (the excl grade the
    commit writes).
  - Each builder computes its types with the inference's file-local helper.
- **Result types stay in the text where a grade can differ.** `cell.init`'s
  result prints through L03's `custom<CellResult>`, and only when it is not the
  inferred owned box. The commit writes `!idr.excl` on a box (today's
  `tests/lower-exclusive/lower-exclusive.mlir:13`), and an unprinted excl result would
  reparse as owned and break its uses. update3's "writes no result types"
  holds for the destinations. ODS cannot infer only the remaining results
  ("type of result #1 … is not buildable"), so L03's `custom<CellDests>`
  calls `CellInitOp::destTypes`: one source.
- **`fillsCell`** is declared by your S28 hunk in `IdrDialect.h`'s `detail`
  namespace, because the CPred is compiled in `Ops.cpp`. It returns `fields +
  holes == constructor's field count`, and that each given field fits.
  - "Fits" is one file-local rule in `OpsCon.cpp`: the field's type, or that
    type owned at the value's permission.
  - `ConOp::verify` uses the same rule with its detailed error.
  - `fillsCell` is total.
- **Unpack declares `Idr_ConsumesOnly`** (the take of its owned value). mlir-5
  says "no memory effect", but an atom's unpack has no results. Pure, it would
  be trivially dead, and erasing it would leave its owned value unconsumed.
- **`Idr_OwnedToken` loses its `builderCall`.** Recycle and take print the

- **`idr.con` (L03's ODS):** its `(type, tag, fields)` builder, its effects with
  no stack branch, no `getField`/`getDest`, and a fold with no holes test.
  `FieldOp::fold`/`canonicalize` read `con.getFields()[index]`.
- **`Idr_OwnedOp` stops setting `hasVerifier`** (ir-ods-5). `Idr_DupOp` sets it.
- **`Idr_SameValue` (S11).** Add the trait (declared by L05 in `IdrBase.td`;
  L04 gives its text) to the trait lists of `Idr_BorrowOp`, `Idr_LinEnterOp`
  and `Idr_LinUseOp`, beside their `Idr_ResultCarriesOperand`. Never add it to
  `Idr_ShareOp`: a share forgets exclusivity, so following it would prove a
  shared cell exclusive.
