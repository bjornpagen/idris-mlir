Fixed decisions:
- **Types (idris-frontend-4).** In `Prims`:
  `data FixedTy = FInt | FInt8 | FInt16 | FInt32 | FInt64 | FBits8 | FBits16 | FBits32 | FBits64`,
  `data IntTy = Fixed FixedTy | Big`,
  `data Ty = TIntegral IntTy | TDouble | TChar | TString` (constructor names
  free of Prelude's `Int`, `Integer` and `Integral`); `width : FixedTy -> Width`
  and `bounds : FixedTy -> (Integer, Integer)` total; `tyName` prints every
  type as today; `fixedTys : List FixedTy`; `int = TIntegral (Fixed FInt)`,
  `integer = TIntegral Big` as values; `Eq` per level by an index;
  `sameIndex` on `FixedTy` (9 clauses); `sameTy : (a, b : Ty) -> Maybe (a = b)`
  by structure. The order lists `integralTypes`, `numTypes`, `primTypes`
  stay, in Idris's order.
- **Shared expressions move to `Prims`.** `TwoLevels` cannot import `Fuzz`
  (Fuzz imports TwoLevels for `twoHosts`, which `tests/fuzz/two-hosts/Main.idr`
  calls as `Fuzz.twoHosts`), so idris-frontend-7's `Expr` is `Prims`':
  `data Sign = NonNegative | Negative`; `Args` and `Expr` move from `Fuzz`
  to `Prims` with `IntLit : (i : IntTy) -> Integer -> Expr (TIntegral i)`,
  `DoubleLit : Sign -> (magnitude : String) -> Expr TDouble`,
  `CharLit : Char -> Expr TChar`, `StringLit : String -> Expr TString`
  (idris-frontend-17: values, not source), `App`, and `SData` (the fuzzer's
  helper, kept beside them); `source : Expr t -> String` (an integer in
  parentheses when negative, a Double `(-m)` when `Negative`, a `Char` or
  `String` as `show v`, an application `(f a b)`) and `input : Expr t -> String`
  (a leaf's line of stdin: `show v`, `-m` or `m`, the character, the string);
  `printer : Ty -> String -> String`, `onHost`, `hostReason : Expr t -> Maybe String`
  (the first libm primitive's `p.name ++ ": " ++ why`) move with them.
  `show` escapes a digit after a numeric escape (`\&`) on both hosts, which
  is what `unescaped`'s comment relied on no pool doing.
- **Two levels (idris-frontend-7, -8, -10).** `record Term where constructor MkTerm; ty : Ty; text : String; host : Maybe String`;
  the primitive corpus is `prims >>= \p => map (term p) (argumentSets p)`
  with `term p as = MkTerm p.result (source (App p as)) (hostReason (App p as))`
  and `argumentSets : (p : Prim) -> List (Args p.args)` total. It keeps
  every argument today's corpus gives (so every base line re-keys by its
  text, `(prim__cast_DoubleString 0.1)`'s duplicate kept once) and adds the
  missing primitives' (Implement 5). An expected line is
  `<term text> = <value>`; the program keeps printing `t<n> <value>`, and the
  checker, which builds the same corpus, maps `n` to the term.
  `TwoLevels.checks : List (String, Bool)`: every `p` of `prims` has an
  argument set (the §7 count equals `length prims`); every term's text is
  unique; no term's text holds ` = `.
- **Semantics names (idris-frontend-8).** A test is one (fixed type,
  operation): `prim-<type>-<spelling>`, the type `toLower (tyName …)`, the
  spelling `Prims.spelling` (exported): `prim-int8-add`, `prim-int8-lt`,
  `prim-int8-shl`, `prim-int8-cast` (all casts from one type are one test).
  16 per type, 144 in all, each at most 72 cases (signed `div`/`mod`).
  `maxCases = 120` stays, a cap no longer met by chunking but stated as
  `Sem.checks : List (String, Bool)` ("every table holds at most 120
  cases"), printed in `twoHosts`; chunks and part numbers go.
- **Checkers (idris-frontend-10).** Pure checks in the generator modules
  (so both hosts compile them); file reading in `Main`.
  `runtests --fuzz-check (overran|agree|model|first) (program <seed> <cases> <part> | replay <tape> <part>) [<stdout-file>]`
  (`overran` takes no stdout file): each regenerates the cases and prints
  exactly the lines `lib/fuzz.sh` puts in one file today (`overran`: the
  `<seed>: overran: case <n>` line; `agree`, `model`: the awk's messages,
  word for word; `first`: `<n> agree` or `<n> model`, a disagreement first,
  or nothing). Labels lose `L` (`d<n>`, `j<n>`, `r<n>`, `s<n>`); the checker
  knows each case's labels, host dependence and model. The overrun comment,
  the model file (`--fuzz-program … model`, `Written.models`) and the label
  grammar go. `runtests --two-levels-check <corpus> <stdout-file> <expected-file>`
  prints the `<corpus>: not compared, host-dependent: <reason>: <text>`
  lines, then `<corpus>: prints expected-<corpus>, the host-dependent terms aside`
  or `<corpus>: prints otherwise` and at most 20 lines `  | <text> = <expected>, printed <value>`,
  `  | no expected value: <text> = <value>`, `  | not in the corpus: <text>`,
  `  | printed nothing: <text>`, by text. A shell reads no Idris fact.

- **Gen and Prims (idris-frontend-15).** `weighted : (w : Weights n) -> Gen (Subset (Fin n) (\i => IsSucc (index i (weightsOf' w))))`
  (`weightsOf' : Weights n -> Vect n Nat`; the proof is `pickFrom`'s `FZ`
  arm), with lemmas that `zeroed` keeps the kept option's weight and that a
  positive element makes `weightSum` positive, so `swarm` has no `No` arm;
  `spans` by the `halfRec` view of `Data.Nat.Views` (powers of two up to
  `n`: none for 0, else twice those up to `n / 2`, then 1), no bound;
  `shrink` on `SizeAccessible` of `length t + tapeSum t` (`tapeSum` a local
  structural sum, which reduces in proofs, unlike `Foldable`'s `sum`), each
  candidate built with its erased `LT` proof. `Prims.bitLength` keeps its
  bound: `Integer` is a primitive with no lemma relating its halving to a
  `Nat` measure, and `halfRec` on its magnitude as a `Nat` would take as many
  steps as the value (2^128 in the pools); say so as essential.
