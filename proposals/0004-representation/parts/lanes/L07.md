**Fixed decisions:**
- Types in `Layout.h`, namespace `idr::layout`, exactly:
  - `struct Component { mlir::Type type; bool counted; };` (S20).
  - `struct Slot : Component { unsigned offset; };` (a component placed in a cell or an element; the type and the bit held once).
  - `struct OwnWord { mlir::Type type; unsigned offset; int64_t value; };`: a word after the header that a cell holds of itself, by value.
  - `struct Cell { SmallVector<SmallVector<Slot>> fields; unsigned size; unsigned objs; SmallVector<std::pair<unsigned, unsigned>> order; CellInfo info; SmallVector<OwnWord> words; };`, `words` in address order: the count word (`i64`, value `objs`) when the header cannot count the object slots, then the group word (`i64`, value `idris_rt_small_word(group)`) for a grouped sum. `Cell::group` and `Cell::countWord()` go. The header (count, info) is not in `words`: its info word has three writers with three values (the cell's own, the stack-marked one, a memo state's or'ed with the loaded stack mark), and its count is the one parameter, 1 on the heap and in a frame, 0 in static data (narrowing conversion-4's "info as an OwnWord"; say so in the handoff).
  - `struct BoxLayout { std::optional<unsigned> group; SmallVector<Cell> cells; const Cell &cell(Tag tag) const; };`: `group` is the offset of the group word in every cell of a grouped sum; `cells` by tag, each at its allocation size (a memo sum's at its largest state's, computed before the `BoxLayout` is stored).
  - `struct SumLayout { std::optional<mlir::IntegerType> tag; SmallVector<Component> words; SmallVector<SmallVector<SmallVector<unsigned>>> fields; ArrayRef<unsigned> slotsOf(Tag, unsigned field) const; };`: `words[0]` is `Component{*tag, false}` when `tag` is set, built only in `sumLayout`; `fields` holds absolute indices into `words`. `slots`, `counted`, `types()` and `offset()` go; the tag optional stays (fewer than two constructors have no tag word: essential).
  - `struct Fixed { int64_t value; }; struct Carried {}; using DescriptorField = std::variant<Fixed, Carried>;` and `struct DescriptorFields { DescriptorField offset; SmallVector<DescriptorField> sizes; std::optional<SmallVector<DescriptorField>> strides; unsigned carried() const; static DescriptorFields of(mlir::ShapedType type); };`. `strides` is none for an identity layout and a tensor (row-major products of the sizes, computed where needed): no stride is "derived" alone, so there is no per-field `Derived` case. `of` reads every non-identity layout through `MemRefType::getStridesAndOffset` (`StridedLayoutAttr` and `AffineMapAttr` alike); a layout it refuses is `llvm::reportFatalInternalError` naming the type and saying the program's verifier refuses it (L03's rule), never an empty stride list.

It is the one decision of "no runtime form": `layout::components` returns `{}` by it, first, and no other arm returns an empty list. L03's `rootKind` reads it.
