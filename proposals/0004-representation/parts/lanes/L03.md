2. **Effects, one property per op (S6, mlir-12).** On `Idr_FuncOp` and
   `Idr_CallOp`: `DefaultValuedProp<NamedEnumProp<Idr_Effect, "effects">,
   "::idr::anyEffect">:$effects`.
   - Upstream's `NamedEnumProp` prints and parses itself as `effects<io,
     crash>`, through the generated `FieldParser<::idr::Effect>` and
     `operator<<` that `IdrEnums.h.inc` already has. So `Idr_EffectAttr` has no
     reader, and L17 deletes it (S6 holds; update3 C asked which).
   - The call's format adds `($effects^)?` after `` `(` $args `)` ``. The
     generated printer prints it only when it is not `anyEffect`; this was
     checked with the pinned `mlir-tblgen`.
   - The function's parser reads an optional `effects<…>` before the symbol
     name: `parseOptionalKeyword("effects")`, then `<`,
     `FieldParser<Effect>::parse`, `>`, and it sets the property. Then it calls
     `parseFunctionOp` as now. A property is not in `result.attributes`, and
     `parseFunctionOp` cannot host it later.
   - The printer prints ` effects<…>` when the property is not `anyEffect`, then
     calls `printFunctionOp` (`idr.func effects<io> @f(…)`).
   - The fixture lines change wave-wide; the coordinator's script rewrites them
     (update3 B).
3. **A call carries its effects (mlir-12).**
   - `CallOp::getEffects` is `effectInstances(getEffects())`, then
     `consumedEffects`, then `Allocate` on each result whose type `isLinear`, in
     `LinResource`. That keeps CSE from merging two calls that each give a
     fresh linear value, and `wouldOpBeTriviallyDead` still erases an unused
     one.
   - `CallOp::build(FuncOp, …)` copies the callee's effects.
   - `CallOp::verifySymbolUses` also holds `bitEnumContainsAll(call.getEffects(),
     callee.getEffects())`, naming the call, as it checks the types.
   - `void writeEffects(FuncOp fn, Effect effects, const mlir::SymbolUserMap
     &users)` in `Func.h` sets `fn`'s property and every `CallOp` user's. It is
     the one writer, which L09's solve and L11's Waves call where no worker
     holds the callers.
