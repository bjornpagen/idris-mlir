Fixed decisions:
- `getYieldTargets()` is a member in each parent's `extraClassDeclaration`:
  `TabulateOp`, `TabulateIOOp` return `getArrays()`; `FoldLastOp`,
  `ScanLastOp` `getResults()`; `ArrayUpdateOp`, `ElementUpdateOp`
  `getODSOperands(0)` (the operand's range; a `ValueRange` of the temporary
  `getArray()` dangles).
- With `targets` the parent's and `k = min(targets.size(), values.size())`,
  the yield forwards `values[k..)` and flows `values[i]` into `targets[i]`.
  The `min` is the half-open coordinate for a yield `RegionBranchOpInterface`
  checks before the parent's `verifyRegions` refuses it; it replaces the
  `count == 0` and `at < size` tests.
- The array yield's parent rule is `PredOpTrait<"its parent holds the arrays
  it yields into", CPred<"::llvm::isa_and_nonnull<::idr::YieldTargetsOpInterface>($_op.getParentOp())">>`
  (ir-ops-2 deletes the `ParentOneOf` list; upstream's `PredOpTrait`).
- Carrier relations are upstream's `TypesMatchWith` with one comparator,
  `defvar Idr_SameCarrier = "[](::mlir::Type a, ::mlir::Type b) { return
  ::idr::unrestricted(a) == ::idr::unrestricted(b); }";` in
  `IdrClosureOps.td` (the hand checks compare carriers only).
- `class Idr_IOTransferOp<string mnemonic, MemoryEffect onBuffer>`, its
  buffer `Arg<Idr_ByteBuffer, "", [onBuffer]>:$buffer`: two ops, two
  declared effects, no flag.
- ir-verify-7 (conditional): a declared `PredOpTrait` on `idr.closure` and
  `idr.suspend`, not verifier code (the MLIR audit): `PredOpTrait<"its result
  is at quantity one exactly when a capture is",

  grade by `def Idr_FnValue : Idr_AtAnyGrade<"::idr::FnType", "a closure at
  any grade">;` in `IdrClosureOps.td`.
