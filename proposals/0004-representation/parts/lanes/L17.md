   ```cpp
   // The part a constructor plays in its sum, by role and never by position,
   // each role holding what only it has: a label names the function it runs
   // and, in a memo sum, whether every force runs it (`byName`: the function
   // reaches an observable effect, so the cell is never written). In
   // CtorRole's order, the case the syntax, the bytecode and KindRule name.
   namespace role {
   struct Plain { bool operator==(const Plain &) const = default; };
   struct ListNil { bool operator==(const ListNil &) const = default; };
   struct ListCons { bool operator==(const ListCons &) const = default; };
   struct Label {
     mlir::FlatSymbolRefAttr fn;
     bool byName = false;
     bool operator==(const Label &) const = default;
   };
   struct Running { bool operator==(const Running &) const = default; };
   struct Forced { bool operator==(const Forced &) const = default; };
   } // namespace role
   using Role = std::variant<role::Plain, role::ListNil, role::ListCons, role::Label,
                             role::Running, role::Forced>;
   static_assert(std::variant_size_v<Role> == getMaxEnumValForCtorRole() + 1,
                 "a role per CtorRole case, in its order");
   inline CtorRole kindOf(const Role &role) { return static_cast<CtorRole>(role.index()); }
   struct Ctor {
     mlir::StringAttr name;
     llvm::ArrayRef<mlir::Type> fields;
     Role role;
     bool operator==(const Ctor &) const = default;
   };
   ```

2. **S18: `#idr.con`'s parameters** are `DataType $data`, `Idr_TagParameter
   $tag`, `ArrayRefParameter<"::mlir::ArrayAttr"> $cells` (one or more) and
   `DefaultValuedParameter<"unsigned", "0"> $spine`.
   - **The form:** every cell but the last holds the constructor's fields
     without the spine field; the last holds all of them. One cell has spine 0.
   - **Canonical uniqueness is kept:** `joinedAt`, and the rule that a cell
     holding its own constructor ends a run.
   - **Spelling:** a plain constructor is spelled as today. A run is
     `<!T, @C, [1], [2], [3, #idr.con<!T, @Nil, []>] along 1>`.
   - **API:**
     - `get(ctx, DataType, Tag, ArrayAttr fields)`, the longest run, as now.
     - `getRun(ctx, DataType, Tag, unsigned spine, ArrayRef<ArrayAttr> cells)`,
       which re-canonicalizes.
     - `getCtor()`, `getField(unsigned)`, `getFields()`, `getRunLength()`.
     - `unsigned fieldOfCell(unsigned cell, unsigned position) const`: the last
       cell's position as it is, any other through `position < spine ?
       position : position + 1`. This is conversion-9's accessor.
     - `void walkFields(llvm::function_ref<void(mlir::Attribute, unsigned)>)
       const`: every field of every cell, with its index in the constructor,
       never through the spine.

6. **S3's flow edges (`FlowOps.cpp`)**, one `getFlowEdges` per new op:
   - `CellNewOp`: `edges.fresh(getCell())`.
   - `CellRecycleOp`: `edges.release(getTokenMutable())`, then
     `edges.fresh(getCell())`. This is the old reuse op's pair.
   - `CellStackOp`: nothing. The frame lends its cell, so the cell is new to
