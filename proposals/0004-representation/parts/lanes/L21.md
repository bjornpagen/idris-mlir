Fixed decisions:
- **S25 (yours) per A7.** `Resolve.idr` holds
  `record Refusal where constructor MkRefusal; rule : Rule; site : NonEmptyFC; message : String`
  (the three parts of L20's `ModuleRefusal`, its site still Idris's) with
  `Eq` by all three, and `data Rejection = Refused Refusal | ByIdris Error`:
  an error Idris raised, held until the driver renders its message as an
  `Elaboration` refusal (rendering needs `Ref ROpts`, which only the driver
  has). The owner is no field: nothing reads it apart from the message.
  It cannot live in `Errors.idr`: `Errors` imports `State`, whose `TS`
  holds the rejections. No field holds a `RuleCategory` (the rule's ODS
  record gives it). `site : NonEmptyFC` makes a refusal at no location
  unwritable: `siteAt : {auto s : Ref TState TS} -> FC -> Core NonEmptyFC`
  (`Errors`) is the one fallback, to `TS.moduleFC` (a `NonEmptyFC`, L22).
  Rejections stay a `SnocList` in the order found (no `Ord`); a refusal is
  recorded unless an equal one is; a `ByIdris` error unless one prints the
  same (Idris's `Error` has no `Eq`: essential).

  `unsupported (<rule>)` head from the rule), so the Idris side renders
  none: `refusalText` and the phrase's literal go. `rejectWith` throws

  catches it; it is never printed.
