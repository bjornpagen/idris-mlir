**Fixed decisions:**
- **`Pragma`**, in `TTImp.TTImp`'s mutual block beside `ImpDecl'`,
  `public export`, first-order: no field of function type. One constructor
  per action `Idris.Desugar` makes today, its fields the action's
  arguments as the closure passes them, the `FC` excepted (the `IPragma`
  holds it). Constructors, in this order and with these names:
  `InterfacePragma : WithDefault Visibility Private -> List (Maybe Name, RawImp) -> Name -> List (Name, (RigCount, RawImp)) -> Maybe (List1 Name) -> Maybe (WithDocFC Name) -> List ImpDecl -> Pragma`;
  `ImplementationPragma : Visibility -> List FnOpt -> Pass -> List (WithFCRigName (PiBindData RawImp)) -> List (Maybe Name, RawImp) -> Name -> List RawImp -> Bool -> Name -> List Name -> Maybe (List ImpDecl) -> Pragma`;
  `ForeignImplPragma : Name -> List RawImp -> Pragma` (the desugared
  calls); `HideNamePragma : Name -> Pragma`; `HideFixityPragma : Fixity -> Name -> Pragma`;
  `UnhidePragma : Name -> Pragma`; `LazyPragma : Bool -> Pragma`;
  `UnboundImplicitsPragma : Bool -> Pragma`;
  `PrefixRecordProjectionsPragma : Bool -> Pragma`;
  `AmbigDepthPragma : Nat -> Pragma`; `AutoImplicitDepthPragma : Nat -> Pragma`;
  `NFMetavarThresholdPragma : Nat -> Pragma`; `SearchTimeoutPragma : Integer -> Pragma`;
  `PairNamesPragma : Name -> Name -> Name -> Pragma`;
  `RewriteNamePragma : Name -> Name -> Pragma`;
  `PrimIntegerPragma`, `PrimStringPragma`, `PrimCharPragma`,
  `PrimDoublePragma`, `PrimTTImpPragma`, `PrimNamePragma`,
  `PrimDeclsPragma`, each `Name -> Pragma`;
  `CGActionPragma : String -> String -> Pragma`;
  `NamesPragma : Name -> List String -> Pragma`;
  `StartExprPragma : Pragma` (the base's action ignores the term and
  throws `InternalError "%start not implemented"`; so does its
  interpretation); `OverloadablePragma : Name -> Pragma`;
  `ExtensionPragma : LangExt -> Pragma`;
  `DefaultTotalityPragma : TotalReq -> Pragma`. The `Pragma` suffix keeps
  them apart from `Idris.Syntax.Directive`'s constructors, which
  `Idris.Desugar` also sees. Add an import to `TTImp.TTImp` only for a type
  it cannot yet name (`LangExt`, `WithDocFC`, `WithFCRigName`, as needed).
- **`IPragma : FC -> List Name -> Pragma -> ImpDecl' nm`**, its comment
  saying why the pragma is data (a declaration a cell holds never holds a
  closure over a cell). `Show`, `defName`, `getFC` and every positional
  pattern `IPragma fc ns p` stay as they are; a traversal does not enter
  the payload, as the base's could not enter its closure; a TTC still
  throws `"Can't write Pragma"` and reflection `"Can't reflect a pragma"`.
- **The interpreter.** `TTImp.ProcessDecls` declares, with no body and a
  comment naming where it is defined (as `TTImp.Elab.Check` does for
  `processDecl`):
  `processPragma : {vars : _} -> {auto c : Ref Ctxt Defs} -> {auto m : Ref MD Metadata} -> {auto u : Ref UST UState} -> {auto dl : Ref DLY DelayedElabs} -> {auto s : Ref Syn SyntaxInfo} -> {auto o : Ref ROpts REPLOpts} -> FC -> NestedNames vars -> Env Term vars -> Pragma -> Core ()`,
  and `process eopts nest env (IPragma fc _ p) = processPragma fc nest env p`.
  `Idris.Desugar` defines it: a function of its own with one clause per
  constructor, then `TTImp.ProcessDecls.processPragma = <that function>`.
  Each clause's body is the base's closure body, its free variables read
  from the constructor's fields and `fc` from the argument, the cells
  being `processPragma`'s autos (`{dl}` where the base wrote it); no
  clause changes what it calls or in what order.
- **`Idris.Desugar`'s pragma sites** build `IPragma fc <names as today> (<constructor> <fields>)`:
  the pragma argument is always a constructor applied to values (the names
  list keeps its form, `maybe [tn] (\n => [tn, n.val]) conname` at the
  interface). `UnboundImplicits` still calls
  `setUnboundImplicits a` at desugaring as well; `Logging` is still `ILog`.
- **`Pass`** (with its comment, `Eq`, `typePass`, `defPass`, all
  `public export`/`export` as now) moves from `Idris.Syntax`'s mutual block
  to `TTImp.TTImp`, above `Pragma`; its users already import `TTImp.TTImp`.
- **`compiler/idris/README.md`**: the sentences on `IPragma` in the
  delayed-elaborators paragraph and the knot sentences ("`SyntaxInfo` still
  reaches itself that way ... cannot name to give it.") are replaced by
  what is now true: a pragma is `Pragma` data, one constructor per action,
  which `process` interprets through `processPragma`, declared in
  `TTImp.ProcessDecls` and defined in `Idris.Desugar` above the interface
  and implementation elaborators, so no declaration holds a closure and no
  cell's type reaches itself through one; `Pass` lives in `TTImp.TTImp` for
  it. The sentence on the other cells stays.
