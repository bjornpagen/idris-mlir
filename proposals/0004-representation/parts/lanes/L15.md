**Fixed decisions:**
- **ir-verify-11 reads S11, not `flowEdgesOf`.** The flow edges give reads
  that `readFrom` must not report: `idr.force` (`FlowOps.cpp:161-165`),
  `idr.array.get` (`OpsArrays.cpp:217-219`) and `tensor.extract` would make
  every force's value a view of its cell. They give no edge for a word field,
  and no `memref.load` model.
  ```cpp
  Value idr::ownership::readFrom(Value value) {
    Source source = sourceOf(value);
    if (const auto *field = std::get_if<Field>(&source))
      return field->scrutinee;  // a field read, a case's binding, a memo cell's part
    // then ViewLikeOpInterface's source and a counted memref.load's buffer,
    // as today; else null.
  }
  ```
  The `FieldOp` and `MatchOp` arms go; upstream's buffer cases stay.
- **`viewedFrom`:** `readFrom`, else `sourceOf`'s `Same`. A default region's
  argument is the scrutinee itself, by S11's own rule. `Same` follows the
  trait `Idr_SameValue`, which `idr.share` lacks (update3 B), so `viewRoot`
  and `isStatic` stop at a share. Its result holds the reference its operand
  gave up, so a view of it is a view of the result.
- **`readBy` is unchanged.** mlir-9 is withdrawn, so a match forwards nothing
  into its default region, and the scrutinee stays among what the match
  reads. Its default region's argument is made (`make`) as a view of the
  scrutinee: the same value, by the rule `sourceOf` states.
- **ir-verify-18.** In `Verify.h`: `enum class Role { Untracked, Owned,
  Carried, View };`. `Role roleOf(Value)` is memoized in
  `DenseMap<Value, Role>` and decided from the type and definition, in this
  order:
  1. `!holdsReferences(type)` or `ownership::isStatic(value)` → `Untracked`;
  2. `isOwned(type)` or `isLinearByType(type)` → `Owned` (a cell is used once
     by its type and holds references, so it owns them; it is checked before
     the next rule, though its producer allocates);
  3. an `OpResult` its op allocates, or `idr.own.give`'s result → `Carried`;
  4. otherwise → `View`.

  The state is one `DenseMap<Value, Slot>`, with `using Slot =
  std::variant<References, Viewing>`, `struct References { int count; }` and
  `struct Viewing { llvm::SmallVector<Value, 1> owners; }`. The name `Held` is
  `idr::Held`'s (`IdrDialect.h:240`). The undo log records `References`
  only, as `held` today. Each predicate chain becomes `switch (roleOf(v))`,
  and the four roles are essential.
- **ir-verify-19:** a `Knot { SmallVector<unsigned> members; unsigned named;
  std::optional<Location> at; }` and an `ArrayIn { Knot *knot; unsigned
  member; }`. `knots` is a `SmallVector<Knot>`, built whole before any
  pointer into it is taken. An array type maps to `ArrayIn` and a data type
  to `Knot *`. `ArrayIn` is a record because `TypeGraph` gives no member
  index of a type.
- **mlir-4:** `verify::knots(ProgramOp, const TypeGraph &)` keeps its
  signature and its text. It becomes the body of L13's check pass
  (`getAnalysis<TypeGraph>()`), and L03 drops its call from
  `verify::program`. `Verify.h`'s comments follow: the program's rules run in
  `idr.program`'s region verifier, and knots in their pass. The pass's
  declaration and its two-line `runOnOperation` are L13's (a Transforms
  unit); report that no §4 text names them.
