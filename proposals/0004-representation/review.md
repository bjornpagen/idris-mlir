# Adversarial review of the 0004 packet

Reviewed at the working tree of 2026-10-17 (base 73d6dcf3 plus the
uncommitted checker), against the live source, the pinned MLIR in
`.toolchain/llvm-project/mlir` and `upstream/`. Everything below was checked
by reading the cited line or by running a script over `ownership.json` and
`findings/` (file coverage, per-finding write sets, `assemble.py`'s matching).

## Verdict

**Executable after named concrete prerequisites.** The partition is disjoint
on files (no file is covered by two lanes; every `tests/idr/*` directory and
every `foreign/idr`, `compiler/src` and `runtime` file has an owner) and the
findings are sound. The packet was not executable as written, for three
reasons found in the source:

1. S5 would crash or free live calls (the erase sits where the new blocks are
   not yet joined, and between two inlines).
2. Two files, `IdrDialect.h` and `IdrBytecode.td`, and one more,
   `runtime/idris_rt.h`, were edited by four to six lanes' findings each while
   `ownership.json` gave each to one lane that was not the one that needed
   most of the edit.
3. Several ODS and C seams were fixed by prose that names no spelling
   (`idr.con`'s token, the guard cases, the ABI word, `Idr_ByteBuffer`, the
   reserved names), so lanes writing `.td` files at the same time could not
   agree, and one named definition (`Idr_ByteBuffer`) cannot be written where
   S17 puts it.

I made the corrections the evidence determines in `README.md`,
`ownership.json` and `assemble.py` (listed below). The prerequisites that
remain are the owner's or the drafters':

- **P-1.** Commit the checker first. `git status` shows
  `Frontend/Growth.idr` untracked and a dozen frontend files modified, and
  the Idris lanes run `git archive HEAD`.
- **P-2.** The drafters of L02, L03, L04, L05, L06, L07, L08, L11, L16, L17,
  L19 and L24 must conform to the edited README (the table of corrections
  names each). `parts/lanes/*` is theirs and was not edited here.
- **P-3.** Integration follows README §8.2 as edited: S28's hunks, CMake
  source lists reconciled with the tree, ODS targets alone first, then
  `make typecheck`.
- **P-4.** The owner decides the disagreements below, D-A and D-C first.
