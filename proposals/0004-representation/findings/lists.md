# Lists used for what a list is not: candidate sites

The owner (2026-10-17) approved targeted structure changes over a blanket
rewrite to linear arrays, as part of this cutover: a `List` is for
sequential consumption only. Each finding below lists, for one Idris lane,
the sites a scan found (at the packet's base, comments excluded) of the five
patterns that are a list misused when the value is a `List`:

- **concat:** base's `concat`/`concatMap` over a `List` fold `++` from the
  left, so a join copies everything joined before it (measured: about
  780 s of the self compile's growth phase before the walk fix);
- **append:** `xs ++ [x]` in a loop, quadratic;
- **position:** `index`, `indexMaybe`, `getAt`, `elemAt`, `!!` into a `List`,
  linear per access, and a bound checked at run time that a `Fin` proves;
- **assoc:** `lookup` on an association `List (k, v)`, linear per lookup;
- **membership:** `elem`/`nub` inside a walk, quadratic.

The scan is syntactic: `lookup` on a `SortedMap` and `index` into a `Vect`
are already the right structure and stay. The lane decides each site.
