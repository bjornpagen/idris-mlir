Fixed decisions:
- **Exports** (§4.4, verbatim):
  ```idris
  public export
  record Fields where
    constructor MkFields
    arity : Nat                    -- the implementation's own parameters, where a Dispatches' arguments start
    fields : List (Template, Root) -- its fields, over those parameters, each with its dictionaryRoot;
                                   -- a hand-built dictionary's constructor fields likewise
  export fieldsOf : {auto c : Ref Ctxt Defs} -> {auto s : Ref TState TS} -> Address -> Core (Maybe Fields)
  ```
- **`fieldsOf a` reads one definition:** `nameAt (gamma defs) a`, then `lookupCtxtExact`. A name that is not there gives `Nothing`.
- **A constructor (`DCon _ n _`), data or interface:** `Just (MkFields n [(Var 0 0, Parameter 0 0), …, (Var (n-1) 0, Parameter (n-1) 0)])`.
  - A constructor's fields are its own parameters. A field of a constraint tuple (`MkPair`), of a record holding a dictionary (`MkHasEq`), or of a dictionary built by hand (`MkEq`) is then "one of J's own variables", and G8 takes the flow there (§4.7).
  - This is the one place the coordinate is chosen. No consumer distinguishes a constructor from an implementation.
- **An implementation:** a `PMDef _ args (STerm _ body) _ _` whose `type` satisfies `implementationType`, the definition `gives` accepts (Terms.idr:773-780).
  1. **Mark its parameters.** `staticsOver owner (length args) (type def) (map (\i => Just (markerAt i 0, False)) [0 .. length args - 1])`. A parameter of a static kind stands as `markerAt i 0`; a non-static one as `Erased EmptyFC Placeholder` at quantity 0, else `Erased EmptyFC Impossible`, as `closeWritten` writes a runtime value.
  2. **Close the body** with `closeWritten` (each entry as `TypeValue`), then take `whnf`. `Built C cargs` gives the fields; `Stuck _` gives `Nothing`.
  3. **Read C's type** (`normaliseClosed (type defC)`) as `paramLayout` probes it, for the quantity and the binder type of each argument b.
  4. **Field b**, by C's binder b:
     - quantity 0 (the interface's own type arguments): `(templateOf AType cargs[b], dictionaryRoot cargs[b])`;
     - a dictionary binder (`dictionaryBinder`; a parent): `(templateOf ADictionary cargs[b], dictionaryRoot cargs[b])`, the root `implementationOf` names, never the written head: a parent written `snd (MkPair x d)` roots at d's implementation;
     - anything else, a method field. Count its leading lambdas, then strip that many, substituting `Erased EmptyFC Placeholder` for each bound variable. The result is `M a⃗` with `M` a definition: give `(Head (definitionAddress (gamma defs) M) ts, Implementation aM)`, where ts is `templateOf k a` for each `a` that `staticsOver` over M's type makes static at kind k, in order, and aM is M's address. Its Root is the method function, which is all §4.7's `reaches` reads of it.
     - A method field whose stripped body is no definition applied: `(Leaf 1, Unrooted)`. It is escalated below.
  5. `arity` is `length args`: the method function takes the implementation's parameters first (Terms.idr:991-997), so a Dispatches' argument q lands at `arity + q`.
- **Anything else** (a function with a case tree, a primitive, a type constructor): `Nothing`.
- **No stand-in of your own.** The only markers are G1's `markerAt`, and the only reductions are `whnf` and `normaliseClosed`.
- **Totality:** no `assert_total`, `covering` or `believe_me`. The one recursion is stripping a counted number of lambdas, on that `Nat`; everything else is a fixed sequence of Core calls.
