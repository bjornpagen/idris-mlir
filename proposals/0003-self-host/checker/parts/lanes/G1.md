- **Shared rules, in this order** (the first that applies):
  1. `Erased _ (Dotted u)` is read as `u`.
  2. **A runtime part is `Leaf 1`,** one key node. That covers:
     - `Erased _ Placeholder` and `Erased _ Impossible`: an unbound binder (the placeholder a binder's variable becomes, below), a part cut or holed at runtime;
     - a `Ref _ Bound n` that is no marker of G1's and no hole marker;
     - a `Ref _ Func n` with no place in the context (`getNameID n (gamma defs)` is Nothing: `unknownPart`, cutRuntime's runtime variable), as `normalHead` reads it;
     - an unsolved `Meta`.
  3. **A hole marker** (`Closed.markerOf n = Just i`, Closed.idr:1006) is `Token (S i)`: one `Number (Shaped Marker) i` token in the key, of height 1.
  4. **A marker of G1's families** reads as its family says: `markerAt i d` as `Var i d`, `fieldAt i d path` as its nested `Field`s over `Var i d`, `heldAt c p` as `Held c p`. Applied to arguments, it is `Head Nothing (<that reading> :: args read)`.
  5. **A closed run** is `Leaf (S n)`: `n >= 1` applications of one successor (`natRole` `Succ`, the same `definitionAddress` at each step) ending in a constructor whose `natRole` is `Zero` (Keys.idr:365-376).
     - `S n` is the model's height of `S^n Z`, which a template's explicit successors must bound. `S (S (Var i 1))` closes, at an instance, to a run one longer than the one `Var i 1` was matched in.
     - A run that ends in anything else is read node by node.

  A literal's height is its node's, never its magnitude: a height at a literal's weight makes K about 2^31 for `So (x < 2147483647)` (README §4.3). Its weight is `heaviest`'s.
- **`read AsType`**, after the shared rules and constants:
  - `Bind fc _ b sc` is `Head Nothing (parts ++ [read (subst (Erased fc Placeholder) sc)])`. Here parts is `[read ty]` for `Pi`, `Lam`, `PVar` and `PVTy`, and `[read v, read ty]` for `Let` and `PLet`. The bound variable becomes a placeholder: a `Leaf 1` of the same height, and every term stays closed.
  - `TDelayed _ _ u` is `Head Nothing [read u]`. `TDelay _ _ ty a` is `Head Nothing [read ty, read a]`. `TForce _ _ u` is `Head Nothing [read u]`. `As _ _ a p` is `Head Nothing [read a, read p]`.
  - On `getFnArgs t = (f, args)`:
    - **A constructor.** `f` is a data or type constructor `n`: `Head (definitionAddress (gamma defs) n) (map read args)`.
    - **A projection.** `f = Ref _ Func n`, `!(projection n) = Just pr` and `length args >= length pr.params`. The record is `getAt pr.matched args` (first argument first, as `Closed.params`). With no arguments past the projection's own, the result is `Field pr.field !(read … record)`; otherwise `Head Nothing (Field pr.field … :: map read extras)`. The normaliser has projected every constructor record, so this one is none.
    - **Another definition.** `f = Ref _ Func n` with a place: `applied AsType w acc n args`.
    - **Any other head:** `Head Nothing (!(read … f) :: map read args)`.
- **`read AsShape`**, after the shared rules:
  - a data constructor applied: `Head (Just addr) (map (read AsShape …) args)`;
  - `Ref _ Func n` with a place, projections included: `applied AsShape w acc n args`. A projection of a value is a match on it, and its field is a part of the value: the walk gives the −1 it is, and no dictionary is involved.
  - anything else (a literal, a type constructor, a binder, a delay): `Leaf 1`, which `skeleton` makes a hole.
- **`readWritten`**, after the shared rules: a data constructor applied is `Head (Just addr) (map readWritten args)`, and anything else is `Leaf 1`.
  - This is `skeleton`, keeping the markers.
  - Nothing is normalised or unfolded: a call in a written shape is a hole in its key (`count (S (plus m (S Z)))` keys `S _`).
- **`readDictionary`**, after the shared rules and constants:
  - binders, delays and `As` as `read AsType`;
  - a data or type constructor applied: `Head (Just addr) (map readDictionary args)`;
  - a projection applied to its parameters whose record is not a data constructor application: `Field pr.field (readDictionary record)`, with extras as in `AsType`;
  - **any other definition applied**, a projection of a constructor included: `Head (Just addr) (map readDictionary args)`, as the key writes it. So `Functor (Vect (S (length {P15} xs)))` is `+3` at P15: `length`'s `Head` sits at depth 3.
- **`applied r w acc n args`**: a definition left applied in a type's normal form or a shape's. Let `folded = Head (Just addr) (map (read r …) args)` for `AsType`, and `Leaf 1` for `AsShape`. By `lookupCtxtExact n`:
  1. **Folded.** It is not a `PMDef`, or its `treeCT` is `STerm` (no match), or it is applied to fewer arguments than its parameters. The normaliser leaves it applied whatever its arguments (its visibility, an implementation under `normaliseTypes`, a builtin, a partial application), so it is applied at every instance too.
  2. **Opaque.** `enter (gamma defs) n w` is Nothing: the definition is already being unfolded on this path. The result is `Opaque addr (map (read r …) args)`.
  3. **Structural.** Otherwise, with `Just (Element w' less)` from `enter`, `structural r w' (rec w' less) n args` (below). When it holds, its reading is the result.
  4. **Walked.** Otherwise, `walk r w' (rec w' less) folded env treeCT extras`. `env` binds the parameters to the arguments, first argument first, and `extras` are the arguments past them. Nothing (an absurd tree) gives `folded`.
- **`structural`**, a recursion that is structural on one Nat-like argument (README §4.3). It holds when all of these do:
  1. `treeCT` is `Case idx _ _ alts`, and the argument at `idx` is `markerAt j e`.
  2. Every alternative is `ConCase c _ cargs (STerm _ rhs)` with `natRole` of `c`'s definition set (Zero or Succ), or `DefaultCase (STerm _ rhs)`. The argument is Nat-like, and the tree is one level deep.
  3. Bind the parameters to `args` and every `cargs` to `markerAt j (S e)`, substitute into each `rhs`, and `normaliseClosed` it. A recursive call is an application of `n` itself, by `getNameID`.
     - **The `Succ` leaf** (the only one that mentions `n`) is a recursive call, or a data or type constructor applied to children each of which is a recursive call or closed.
     - **Every recursive call** has `markerAt j (S e)` at `idx`, and at every other position a term `==` (Core.TT's) to `args` there. That is the predecessor step, with the other arguments unchanged.
     - **Every other leaf** is closed.
     - **Closed** means: no marker of G1's families (`Closed.mentions`), and no mention of `n`.
  4. Then `c = minus (max B S') 1`, where B is the tallest other leaf and S' the tallest closed child of the `Succ` leaf (0 if none), each read with `r` under `w'`.
  5. The reading is `Choice (Var j e) (otherLeaves ++ [raise c (Var j e)])`, where `raise c t` puts `c` levels of `Head Nothing [_]` above `t`.

  Its comment carries the proof, by induction on the argument v, with `h(v) = k + 1` for k successors: `h(n Z) <= B <= 1 + c`; `h(n (S k)) <= 1 + max(S', h(n k)) <= 1 + h(k) + c = h(S k) + c`, since `h(k) >= 1` and `c >= S' - 1`. So `h(n v) <= h(v) + c`, which is the reading's weight from `Var j e`.
  - `Ints (S k) = (Int, Ints k)`: B = S' = 1, so c = 0, and `Ints (Var j e)` reads `Choice (Var j e) [Leaf 1, Var j e]`, weight 0.
  - `Pad (S k) = Pad k`: c = 0, the same.
  - A leaf that holds another marker is no closed leaf (`F a Z = a` grows by a sum, which no template states), so it is walked, and its recursion is `Opaque`. So are a deeper step, a recursion on a non-Nat value, a nested case tree, and two heads per level (`(Int, (Int, F k))`).
- **`walk`** returns `Core (Maybe Template)`, by the tree:
  - `STerm _ rhs`: substitute `env` into `rhs` (as `Closed.close`) and apply it to `extras`. Then `normaliseClosed` it and read it with `r` under `w'`.
  - `Unmatched _`: `Just folded`. A partial definition stops there at an instance, applied as written.
  - `Impossible`: `Nothing`.
  - `Case idx _ _ alts`, on the term `s` bound at `idx`:
    1. **A data or type constructor `c` with arguments.** Take the first `ConCase` whose name is `c` by `toFullNames` (Cases.idr:692-703), binding its arguments to `s`'s. A count mismatch is `internal`, as Cases.idr:697-698. Else take the first `DefaultCase`. Else `Just folded`.
    2. **`PrimVal _ c`.** Take the first `ConstCase c' _` with `c' == c`, else `DefaultCase`, else `Just folded`.
    3. **`TDelay _ _ ty a`.** Take the `DelayCase`, binding `[ty, a]`, else `DefaultCase`, else `Just folded`.
    4. **A template marker `Var i d`.** The result is `Just (Choice (Var i d) leaves)`, where `leaves` holds each alternative's walk, `Nothing`s dropped. A `ConCase` binds each of its arguments to `markerAt i (S d)`. A `DelayCase` binds both so. `ConstCase` and `DefaultCase` walk their bodies as they are.
    5. **A runtime part** (shared rule 2). `Just folded`: a match on a runtime value is stuck at every instance, so the application stays as written.
    6. **Anything else** (an application stuck in turn, a projection on a non-constructor, an applied marker). The result is `Just (Choice !(read r w' … s) leaves)`, every `ConCase` and `DelayCase` binding its arguments to `s` itself. A constructor's argument is a part of `s`'s value, so `s` bounds it.
- **The stack and its measure.**
  - `read`, `applied` and `walk` are one `mutual` block over `(w : Walked) -> (0 acc : SizeAccessible w)`. It matches `acc@(Access rec)` where `applied` enters a definition (as `Closed.unfolded`, :742-753).
  - Every leaf, and every `Choice`'s first field, is read under `w'` with `rec w' less`. Every other recursion is on a subterm.
  - So the module is total under `%default total`, with no `assert_total` or `covering`. The normaliser is `Host`'s trusted reduction, as everywhere in Closed.
  - `readWritten` and `readDictionary` unfold nothing, and recurse structurally.
- **The measures** (pure, total, structural):
  - **`height`:** `Var`, `Field` and `Held` are 0; `Leaf h` is h; `Token _` is 1; `Head` and `Opaque` are 1 plus the tallest child (0 when there is none); `Choice _ leaves` is the tallest leaf (0 when there is none).
  - **`arity`:** for `Head` and `Opaque`, the larger of `length children` and the children's `arity`; for `Choice _ leaves`, the leaves' largest; `Field _ s` is `arity s`; `Var`, `Leaf`, `Token` and `Held` are 0.
  - **`weigh i t`:**
    - Walk t with the depth `e`, which counts the `Head` and `Opaque` nodes above.
    - Each `Var i d` outside every `Field` gives `Finite e d`. These are combined by P1's `join` (cross-addition).
    - Any `Var i _` under an `Opaque`, inside a `Field` or not, gives `Stuck`.
    - A `Choice` adds no depth, and its first field is skipped. `Held` and `Token` hold no `Var`.
    - The result is normalised to one side 0: `Finite (minus g l) (minus l g)`. No occurrence gives `Absent`. Integer appears nowhere.
  - **`heaviest`:** the largest `Token`'s weight in the template, leaves of a `Choice` included and its first field skipped; 0 when there is none.
  - **`dictionaryRoot t`** (Core): the root of `implementationOf !(solved t)`, never the written head (`snd (MkPair x d)` is d's root). With `getFnArgs` of that form:
    - a reference with a place (an implementation, an interface's constructor, any definition `implementationOf` stops at): `Implementation addr`;
    - `markerAt i d`: `Parameter i d`, the writer's own dictionary;
    - anything else (a lambda, a field or held marker, a hole, `Erased`): `Unrooted`.

    It is the one root function: G5's heads, `Site.roots` and Fields' roots are its result (README §4.3).
  - **`fieldsIn`:** each `Field` or `Held` node, whole, in prefix order, with its projection-rule arc weight.
    - The weight is `Finite (e + 1) 0`, with `e` its depth as `weigh` counts it (the `Head` and `Opaque` nodes above; a `Choice` adds none, and its first field is skipped).
    - It is `Stuck` when an `Opaque` stands above the node: what a recursion computes from a field has no depth bound.
    - It is the projection rule's one reading (§4.6 step 4), so no consumer walks a template for fields itself.
    - It does not descend into a `Field`'s record: a field of a field is read through the outer one, by G8's `roots`.
- **`closedHeight`:**
  - For `ADictionary`: `(height !(templateOf ADictionary t), !(dictionaryRoot t))`. The height is the form the key holds; the root is the implementation that runs.
  - For `AType`, `AForm` and `AShape`: `(height !(templateOf k t), Unrooted)`. Only a dictionary has an implementation at its root.
  - There is one height: a request's argument is read by the same function as a site's template, so the bound check cannot drift from the arcs.
