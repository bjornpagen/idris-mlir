- **Static kinds come from G5's `staticsOver` (§4.5), never from `classify`:**

  - It takes, per argument, its closed written value and whether it is a dictionary, or `Nothing` for a runtime value.
  - It gives each parameter's kind and the rest of the type. It reads no Core type, registers nothing and refuses nothing.

- **The environment is scope-indexed**, the shape of `Closed.Parts` (Closed.idr:578-591), so that an out-of-scope variable cannot be represented:
  ```idris
  data Stand = Fixed Static ClosedTerm   -- a static value: markerAt i 0 (a type or form), or heldAt C p
             | Dictionary Nat Nat (List Nat)   -- dictionary parameter i at depth d, and the fields matched out of it, the first first:
                                        -- its term is markerAt i d for [], fieldAt i d path otherwise
             | Shape ClosedTerm          -- a shape over pattern stand-ins (an AShape parameter, a field of one, or a constructor of them after a match)
             | Erased                    -- quantity 0: Erased EmptyFC Placeholder
             | Runtime                   -- a runtime value: Erased EmptyFC Impossible, as closeWritten has it
  data Env : Scope -> Type where
    Nil : Env []
    (::) : (Stand, Name, Maybe ClosedTerm) -> Env vs -> Env (v :: vs)   -- its stand, its display name, its type when known
  ```
  - A Stand's term closes the scope (`Closed.closeWritten`, with every entry given as `TypeValue term`).
  - A pattern stand-in is `Ref EmptyFC Bound (UN (Basic ("idris-mlir-pattern-" ++ show k)))`, with k fresh along the walk. It is never an `MN` name: the fork's quotation rebinds bound `MN` names by their number (`compiler/idris/src/Core/Normalise/Quote.idr:108-123`), and `staticsOver`, `whnf` and `lambdasApplied` all quote. A `SortedMap Nat (Nat, Nat)` threaded down the tree gives each one its parameter i and depth d. It is Sites' own spelling. Before a template is made, each pattern stand-in is substituted by `markerAt i d` (`substName`), so no other module sees it.
- **The definition's own parameters** mirror `environment` (Programs.idr:117-129):
  - `staticsOver` over d's type, every parameter given as `Just (markerAt i 0, False)`;
  - `AType` and `AForm` give `Fixed k (markerAt i 0)`, and `ADictionary` gives `Dictionary i 0 []`;
  - `AShape` gives `Shape p_i`, a fresh pattern stand-in at `(i, 0)`;
  - `Nothing` gives `Erased` for a binder of quantity 0, else `Runtime`;
  - the type is the binder's type, with the earlier parameters' terms substituted.
- **Leaf matches substitute into `Var i d`** (§4.4). At `Case idx _ _ alts`, take the scrutinee's stand `v` and its type `ty` (normalised: `T r⃗`).
  - **`ConCase C args rhs`** binds C's arguments in order, reading C's normalised type with each binder probed as `Types.paramLayout` probes it, through G7's exported `paramLayout` and its probe `marker` (Types.idr:60-62 and 72-90, `MN "idris-mlir-binder" b`; §4.4, §4.8), so there is one reading. Argument b:
    - erased, and C's result type has b at T's argument p: `r_p` (Cases' `Param`), as `Fixed AType`;
    - erased otherwise: `Erased`;
    - any argument, when `v` is `Dictionary i d path`: `Dictionary i d (path ++ [b])`, whose term `fieldAt i d (path ++ [b])` reads back as nested `Field`s (§4.3). A field of a field keeps its path, never `Erased`: a `Leaf 1` would under-bound the key;
    - a dictionary binder (`dictionaryBinder`) of any other scrutinee: `Fixed ADictionary (heldAt C b)`;
    - a runtime field: when `v` is `Shape _` at `(i, d)`, a fresh `Shape q` at `(i, d + 1)`; otherwise `Runtime`.
  - **Rebinding:** when `v` is `Shape s`, every entry's term has s's pattern stand-in replaced by `C a⃗`, the constructor applied to the stand-ins just made. Later references to the scrutinee then see the match. A `Fixed` or `Dictionary` scrutinee is never rebound: a dictionary keeps its root, the writer's head.
  - **`DefaultCase rhs`:**
    - when `coversAll alts`, it is dead and not walked (Cases.idr:794-797);
    - when `v` is `Shape _` and `siblings alts` is non-empty, walk rhs once per constructor of `siblings alts` not named by the alternatives, each with that constructor's stand-ins and the rebinding above;
    - otherwise walk it once.
  - **`ConstCase`:** walk rhs. **`DelayCase ty arg rhs`:** ty is `Erased`, arg is `v` itself.
  - **`Unmatched`, `Impossible`:** no site.
- **Terms are walked in two modes.** Run mode is code; static mode is a type or a static argument.
  - **Each argument is closed as its key holds it.** For a static argument of kind `AType`, `AForm` or `AShape`, `close env t_j` (the stands' terms, pattern stand-ins replaced by `markerAt i d`). For an `ADictionary` argument, the same, except that every `Runtime` and `Shape` stand becomes `holeMarker k` (Closed.idr:1006), numbered by first occurrence. That is `Terms.holed`'s marking (Terms.idr:686-693), so a runtime-dependent dictionary is the form its key holds, which `templateOf ADictionary` reads in `implementationOf`'s form (§4.3). Its `Site.roots` entry is `(j, dictionaryRoot c_j)` on that same closed term c_j: one root function, in Core, so G8 stays pure.
  - **A definition `f` applied, in run mode:** `Calls f`, at the arguments `staticsOver` makes static, each `(j, k, templateOf k c_j)`, and `roots` for its `ADictionary` ones. When f is projection-shaped (front2.diff's `methodIndex`: one `ConCase` on one parameter, returning a field applied or not), the call is a method call (§4.4):
    - `Calls f` at the projection's own parameters, the first `length params` arguments;
    - beside it, `Dispatches (templateOf ADictionary c_idx) (dictionaryRoot c_idx) k`, where idx is the matched parameter, k the returned field, and c_idx the record closed as a dictionary argument (above). Its Root is the one root function's, as `Site.roots` is (§4.4), so no template's head is ever read as a root. Its arguments are those past the projection's arity (`drop parity`, Terms.idr:912, 1012-1018) that `staticsOver` makes static over the rest of the projection's type (its second result), each numbered from the method's first own parameter.
    - Nothing is settled here. The request is the projection's (§4.5), and G8 takes the Dispatches to J's method function.
  - **A dictionary variable applied, in run mode** (implementationAt, Terms.idr:541-551): `lambdasApplied` of its term applied to the arguments is walked in the `Settled` phase. This is the one settling, so the phase falls once.
  - **A definition `f` applied, in static mode:** `Calls f` only when f's type is an implementation's (`implementationType`). Any other definition applied there is unfolded by `templateOf`, and the translation never requests it.
  - **A data constructor `C` applied, either mode:** when C has dictionary arguments, `Calls C` at them, `(p, ADictionary, c_p)` with their roots, so that the flow sees what a `Held` reads (§4.4). Its type, C's result type after its arguments, is a type the walk reads (next item).
  - **Every `Builds` comes from a type's template, at each type-constructor `Head` in it** (§4.4). That includes heads in `Choice` leaves, in unfolded synonyms and nested ones, and those the written term spells. So `List (Nat, Vector1 a)` builds `List1` and `Pair` at `(Nat, a)`, which the written term alone misses.
    - The types read are: every static argument of kind `AType`, every binder and result type (d's signature, a lambda's, a `let`'s), and every constructor's result type in either mode.
    - For each, take `t' = eraseIndices (canonicalTypeArg t)` (Closed.idr:1172; Types.idr:383-409, G7 exports it), as the data key reads it (Types.idr:612), and walk `templateOf AType t'` (`buildsIn`, Sites' own walk over a `Template`, structural; it matches every constructor, `Token` included, which has no children and builds nothing).
    - At each `Head (Just a) cs` where `nameAt a` names a `TCon`, emit `Builds a` at `(j, AType, eraseIn cs[j])` for each j of G7's `represented`, with its `within` and `writer` the walk's.
    - `eraseIn` (matching every constructor; a `Token` stays itself) sets to `Leaf 1` every child at a nested type constructor's position outside `represented`. That is `eraseIndices`'s rule for the heads that unfolding made, after the term-level erasure has run. An index is then `Leaf 1`; without it, `findIndex`'s `length` inside `Fin`'s index is a false ω (*measured*, coordinator).
    - Static mode reads no `Builds` off the term itself: the template is the one reading.
  - **A function's type parameter** (a `Calls` argument of kind `AType`) is read in full normal form, as its key holds it: `templateOf AType` of the written argument, with nothing erased.
  - **Arguments:** a static argument is walked in static mode, a runtime one in run mode, and an erased non-static one not at all (the translation passes it nowhere).
  - **Binders:**
    - a lambda's and a `let`'s binder types, and d's own runtime binder types and result type (Programs.idr:63-64), are walked in static mode;
    - an applied lambda binds its argument's stand (applyHead, Terms.idr:461-498);
    - an unapplied lambda's variable is `Erased` or `Runtime` by its quantity;
    - an erased `let` binds `Erased` (Terms.idr:421-433).
  - **A metavariable:** its `solution`, entered once on the path (Terms.idr:555-565).
- **A projection's own body is the single site `Dispatches (Var idx 0) (Parameter idx 0) k`** (§4.4, §4.5): its record is its own dictionary parameter, whose root is the writer's head.
  - It applies when d is projection-shaped (`Case idx … [ConCase _ _ cargs (STerm _ body)]`, the head of `body` a `Local` bound by the ConCase at position k) and d's own kind at idx is `ADictionary`.
  - Its arguments are the field's applied arguments that are d's static parameters: for argument q naming parameter j of kind s, `(q, s, Var j 0)`.
  - q counts the method's own parameters from 0 (§4.4). The method function of root J takes argument q at its parameter `arity J + q`, the offset §4.7's `reaches` returns, read from `Fields.arity`.
  - A record projection of a data type (`fst`, `eqOf`) matches a runtime parameter and is walked as any definition.
- **Blocks are definitions:** a case or with block is requested as its own instance, so its positions must exist. Its parent's call of it is an ordinary `Calls` site passing the parent's markers, and `sitesOf` walks the block on its own. Nothing is folded into the parent.
- **The signature is walked for every definition** (§4.4), primitives, constructors, refused and hooked definitions included. A caller's `classify` registers the callee's types (Instances.idr:234, Programs.idr:64, Terms.idr:1185-1195, 1291, 1357, 1577). Each parameter's binder type and the result type are walked in static mode, the parameters marked as above, with `writer` and `within` both d.
- **The case tree is walked only for a `PMDef`** not in `TS.refused` (Programs.idr:51-55) and whose hooks do not answer for its body (`answersForBody`, Profile.idr:70-71). `nameAt` giving nothing gives `[]`.
- **Hooks:** a call that `hooked` turns into a call of another definition is also `Calls` of it:
  - `alias q` (Terms.idr:1271-1276), at the same arguments;
  - a `natOperation`'s library function (Terms.idr:1130-1149), with no arguments.
- **`fc` and `shown`:**
  - `fc` is the reference's FC when it is not empty, otherwise the writer's location (D4);
  - `shown` gives each argument as `showTT` of the term closed with each entry's display name (`Ref EmptyFC Bound name`), never rebound;
  - in `sitesIn`, each G1 marker is shown by the writer's binder name at i, through G1's `markerOf`, and `within` is the argument G9 gives (a field's constructor).
- **Totality:** no `assert_total`, `covering` or `believe_me`.
  - `tree` recurses on the case tree; a default's expansion walks the same subtree once per constructor of a finite list.
  - `term` and `static` recurse lexicographically on the phase, a type Sites declares itself (Terms' `Phase` is plain `export`, so its constructors are hidden, §4.4; `Written p` becomes `p` when it settles), on `Walked` (a metavariable is entered once, `Walk.enter`), and on the term.
  - Each leaf starts a fresh `start` path (Cases.idr:459-461).
