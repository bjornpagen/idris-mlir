Fixed decisions:
- **The address.** A type constructor is found from its address through G5's `nameAt`: `let Just n = nameAt (gamma defs) t`, then `lookupCtxtExact n (gamma defs)`.
  - An address `nameAt` does not name, or a name the context does not hold, is `internal EmptyFC "the growth graph names a type constructor the context does not hold"`.
  - A definition that is no `TCon`, or whose constructors are not known (`Nothing`), has no fields, and gives `[]`.
- **The positions** are `rs <- represented tdef`. A represented argument `j` is the writer's parameter `j` of every `Var j d` the sites read (§4.3), the writer being `T`.
- **A constructor's type** is `normaliseClosed (type cdef)`, as `constructor` reads it.
- **Pass 1, the match.**
  - Descend the type's Π binders, giving binder `k` the stand-in `standIn k`, and take the return type, closed.
  - Its arguments are `snd (getFnArgs ret)`. For each `j` in `rs`, in ascending order, match the argument at `j` at depth 0:
    - **a stand-in `k`** binds `k` to `markerAt j d`;
    - **a type or data constructor's application** (`getFn` is `Ref _ (TyCon _) _` or `Ref _ (DataCon _ _) _`) matches each of its arguments, left to right, at depth `d + 1`;
    - **anything else** binds nothing: a literal, a primitive type, a function's application or a Π.
  - Only a constructor's arguments are parts of the value it matches. A function need not be injective, so its arguments are no parts.
  - A binder bound twice keeps its first binding, in that order. Every binding is sound, because a binder bound twice holds equal values.

  ```idris
  standIn : Nat -> ClosedTerm
  standIn k = Ref EmptyFC Bound (MN "idris-mlir-field" (cast k))

  standInOf : ClosedTerm -> Maybe Nat
  standInOf (Ref _ _ (MN "idris-mlir-field" k)) = Just (cast k)
  standInOf _ = Nothing

  -- The return type of a constructor's type, each binder its stand-in.
  returned : Given vs -> Nat -> TT vs -> ClosedTerm
  returned g k (Bind _ _ (Pi {}) sc) = returned (give (standIn k) g) (S k) sc
  returned g k t = close g t

  constructorHeaded : ClosedTerm -> Bool
  constructorHeaded t = case getFn t of
    Ref _ (DataCon _ _) _ => True
    Ref _ (TyCon _) _ => True
    _ => False

  mutual
    -- What the argument at represented position j binds, at depth d.
    pattern : Nat -> Nat -> ClosedTerm -> List (Nat, ClosedTerm)
    pattern j d t = case standInOf t of
      Just k => [(k, markerAt j d)]
      Nothing => if constructorHeaded t then spine j (S d) t else []

    -- The arguments of an application, left to right, at depth d.
    spine : Nat -> Nat -> ClosedTerm -> List (Nat, ClosedTerm)
    spine j d (App _ f a) = spine j d f ++ pattern j d a
    spine j d _ = []

  bindings : List Nat -> ClosedTerm -> List (Nat, ClosedTerm)
  bindings rs ret = let args = snd (getFnArgs ret) in
    concatMap (\j => maybe [] (pattern j 0) (getAt j args)) rs
  ```

- **Pass 2, the fields.**
  - Descend the type again with `Given`. Binder `k` is given `fromMaybe (Erased bfc Placeholder) (lookup k bound)`, which is `walk`'s `Erased` for every binder no represented position binds.
  - For each binder of quantity other than 0, `a' <- normaliseClosed (close g a)`. A dictionary binder (`dictionaryBinder rig a'`) is skipped. Every other `a'` is a field type.

  ```idris
  fieldTypes : {auto c : Ref Ctxt Defs} -> {auto s : Ref TState TS} ->
               Given vs -> Nat -> List (Nat, ClosedTerm) -> TT vs -> Core (List ClosedTerm)
  fieldTypes g k bound (Bind bfc _ (Pi _ rig _ a) sc) = do
    rest <- fieldTypes (give (fromMaybe (Erased bfc Placeholder) (lookup k bound)) g) (S k) bound sc
    if isErased rig then pure rest else do
      a' <- normaliseClosed (close g a)
      if !(dictionaryBinder rig a') then pure rest else pure (a' :: rest)
  fieldTypes _ _ _ _ = pure []
  ```
