\section{Conclusion}

\egglog unifies both Datalog and \eqsat
  style fixpoint reasoning.
From the perspective of a Datalog programmer,
  \egglog adds fast and extensible equivalence relations
  that still support key database optimizations
  like query planning and semi-naive evaluation.
From the perspective of an \eqsat user,
  \egglog adds composable analyses,
  extensible uninterpreted functions, and
  incremental e-matching,
  thus significantly simplifying
  complex conditional rewrites and
  scalable program analyses.
\egglog's novel \textit{merge expressions}
  for user-specified functional dependency repair
  are the key technical mechanism enabling this
  synthesis of fixpoint reasoning capabilities.
