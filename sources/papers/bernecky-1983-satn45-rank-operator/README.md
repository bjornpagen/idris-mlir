## Provenance

Fetched 2026-10-09 from `https://www.jsoftware.com/papers/satn45.htm` and the files it frames
(`satn45TOC.htm`, `satn45a.htm`) plus `adoc.css`, with a read-only mirror of same-prefix links
(Python `urllib`, no scripts run). This is the open source for Bernecky's rank work: the first
implemented definition of the rank operator (`f⍤r`), frames and cells, and the generalised
scalar extension of frames. Bernecky's APL88 paper "An introduction to function rank"
(DOI 10.1145/55626.55632) is closed (OpenAlex: no OA location) and is recorded as not stored.
